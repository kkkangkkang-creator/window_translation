Window Translation — Windows 10/11 64비트 미리보기

1. ZIP 전체를 새 폴더에 압축 해제하세요.
2. window_translation 폴더의 window_translation.exe를 실행하세요.
   _internal 폴더도 함께 있어야 합니다. EXE만 옮기지 마세요.
3. 자동으로 열리는 설정 창에서 'OCR 준비 상태 확인'을 누르세요.
   기본 Tesseract 엔진과 영어·일본어·중국어 데이터가 포함되어 있습니다.
4. 번역 제공자를 고르면 API 주소가 자동으로 입력됩니다.
   API 키를 넣고 연결 확인 · 모델 불러오기를 누르세요.
   모델 목록에서 선택하거나 모델명을 직접 입력할 수 있습니다.
   번역 테스트로 짧은 문장의 실제 응답을 확인한 뒤 적용을 누르세요.
   Anthropic은 Claude API를 직접 지원합니다. 키와 모델은 제공자별로 기억합니다.
   온라인 번역에는 추출한 텍스트가 전송되며 사용료가 발생할 수 있습니다.
   로컬 서버를 직접 사용한다면 Ollama/LM Studio를 선택하고 설치한 모델명을 넣으세요.
5. Ctrl+Alt+F9를 누르고 번역할 영역을 드래그하세요.
6. 같은 영역은 번역창의 '재번역'으로 다시 읽을 수 있습니다.
   시계 옆 트레이 메뉴에서 자동 재번역을 켜고 끌 수 있습니다.

설정 창을 닫아도 프로그램은 트레이에 남습니다. 종료는 트레이 메뉴에서 선택하세요.
처음에는 게임 창 모드에서 작은 대사 영역으로 확인하는 것이 좋습니다.
전체 화면의 작은 글자 변화와 만화 말풍선 순서는 아직 인식이 불완전할 수 있습니다.
말풍선 위에 번역을 넣는 기능은 아직 없으며 결과를 별도 창에 표시합니다.
PaddleOCR는 이 ZIP에 포함되지 않은 소스 실행용 선택 기능입니다.

오류 기록: %APPDATA%\window_translation\application.log
Windows에서 오류 기록을 찾으려면 Win+R에 위 경로를 붙여넣으세요.

설정 창을 열어둔 채 영역을 선택할 수 있습니다. 창 안의 영역 선택 버튼도 사용하세요.
이전 기본 단축키 Ctrl+Shift+T는 처음 업데이트할 때 Ctrl+Alt+F9로 변경됩니다.
API 모델 목록 조회가 성공해도 모든 모델의 번역 사용 권한을 보장하지는 않습니다.


v0.4: 앱 지정 · 원문 위치 오버레이
1. 설정에서 제공자/API 키/모델을 확인하고 “앱 지정해서 백그라운드 번역”을 누르세요.
2. 번역할 앱을 선택하면 앱 전체를 지속해서 읽습니다. 최소화하지 않고 다른 창으로 가려도 됩니다.
3. 특정 부분만 읽으려면 해당 앱으로 돌아가 Ctrl+Alt+F9를 누르고 영역을 그리세요.
4. Ctrl+Alt+F10: 번역 표시/원문 보기. 클릭은 아래 앱으로 그대로 전달됩니다.
5. 트레이의 “현재 영역 핀”을 끄면 새 번역을 멈춥니다. 이미 시작한 번역은 끝까지 저장됩니다.
6. 설정 > 라이브러리의 “저장할 작품 / 채널”을 지정하면 작품별로 저장됩니다.
   트레이 > 번역 라이브러리에서 작품 필터, 검색, 내보내기를 사용할 수 있습니다.
7. 설정 > 프롬프트의 Assistant 프리필은 지원 모델/서버에서만 사용하세요.
   응답 앞에 넣을 지시문이며 결과에는 서버가 생성한 이어지는 본문을 표시합니다.
   지원하지 않는 모델은 비워두고 시스템 프롬프트로 말투를 지정하세요.
8. 설정 > 오버레이에서 덮어쓰기를 끄면 기존 별도 번역창으로 전환합니다.

앱 지정은 Windows Graphics Capture를 사용합니다. 최소화 중에는 새 캡처를 기다리며,
이미 읽은 글의 번역은 계속됩니다. 앱을 닫으면 대상 지정을 해제합니다.
일부 게임/보호 화면은 캡처를 제공하지 않을 수 있습니다. 창 모드/테두리 없는 창을 사용하세요.
만화 세로쓰기·복잡한 말풍선 위치 인식은 실험적입니다. 인식한 문단마다 번역 요청이 발생합니다.
원문이 같은 문단은 재사용합니다. 긴 번역은 원문 상자에 맞춰 축소됩니다. 전문은 번역 라이브러리에서 확인할 수 있습니다.
모니터 좌표만 지정하는 화면 모드는 다른 앱이 덮이면 그 앱의 글을 읽습니다.
다른 일을 하면서 특정 앱만 읽으려면 반드시 앱 지정을 사용하세요.
